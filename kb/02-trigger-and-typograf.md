# правило без paths и typograf через обёртку: почему так

## Что выбрано

**Правило-триггер загружается всегда.** До 1.5.0 у него стоял
`paths: ["**/*.md", "**/*.html"]`. Claude Code сопоставляет такой шаблон только
с файлами, которые он *читает*, и только *внутри проекта сессии*. Сессия,
открытая в одном каталоге и правящая документацию в другом, правило не получала.
Новый файл, записанный без чтения, — тоже. Измерено по транскрипту сессии,
которая это нашла: десять чтений и записей `.md` в `/home/repos/ru-tech-docs`,
ноль загрузок правила.

**Типографику проверяет `typograf-cli`, но через обёртку**
`skills/ru-tech-docs/scripts/typograf_check.py`. Сам `typograf` на Markdown
непригоден, измерено на 6.2.1:

- он не знает Markdown: `echo "x" -- y` в блоке кода превращается в
  `echo «x» — y`;
- `--lint` показывает одно место на правило и выходит с кодом 0 при находках.

Обёртка прячет код, ссылки, маркеры списков и выделения и печатает каждую
строку, которую `typograf` изменил бы. Коды выхода: 0, 1 или 2.

## Что отвергнуто и почему

- **Расширить `paths:` на `.sh`, `.py`.** Не лечит главное: правило всё равно не
  грузится вне проекта сессии.
- **Vale как носитель всех проверок.** Это бинарник и конфиг в трёх ассистентах
  ради набора, который помещается на экран.
- **`typograf --lint` напрямую.** Причины выше: портит код и молчит о повторах.

## Чего это стоит

- Правило занимает около 1,2 КБ в каждой сессии Claude Code, даже без русского
  текста.
- `typograf` — внешняя зависимость: Node.js 12.20 или новее и npm. Она
  необязательна: без неё проверка 15 пропускается. Установщик ставит её в
  `~/.local` без `sudo`. Node.js через `apt`, `dnf`/`yum` или `brew` ставится
  только после ответа «да» в терминале.
- Выключенные правила `typograf` — список, который придётся пересматривать при
  смене версии. Поэтому версия закреплена: `typograf-cli@6.2.1` в `install.sh`.

## Когда пересмотреть

- Claude Code начнёт сопоставлять `paths:` с файлами вне проекта сессии или при
  записи: тогда `paths:` можно вернуть и не платить 1,2 КБ.
- Новая версия `typograf-cli`: прогнать `tests/test_typograf_check.sh` и обёртку
  на русских README соседних проектов. Шум выше нуля — пересмотреть список
  выключенных правил.
