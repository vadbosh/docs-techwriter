# ru-tech-docs

Скилл `ru-tech-docs`: русская версия английской технической документации и
проверка готовой русской версии. Вместе со скиллом поставляется правило-триггер
`rules/ru-tech-docs-trigger.md` — без него скилл не срабатывает.

С 2026-10-04 скилл живёт только здесь. Канон `~/ai-config-source` его больше не
раздаёт: имя стоит в `BUNDLE` файла `lib/capture.py`, и `index.sh` не тянет
копию из IDE обратно. Правка в `~/.claude/skills/ru-tech-docs/` пропадёт при
следующем `./install.sh` — правь `skills/ru-tech-docs/`.

## Команды

```bash
./install.sh --dry-run    # что перезапишется в каталогах ассистентов
./release.sh check        # версия ↔ журнал ↔ тег ↔ HEAD ↔ копии скилла и правила
tests/test_typograf_check.sh   # обёртка typograf; без typograf печатает SKIP
```

## Задача готова, когда

Вывод команд выше приложен к ответу. Для выпуска — `release.sh check` с
итогом «agreed and released». Правка самого скилла проверяется прогоном на
живом документе, а не чтением.

Сообщение коммита пишется по-английски, вместе с телом.
